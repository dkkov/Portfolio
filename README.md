# Portfolio — Dmitry Kovalev · AI Business Process Automation

Одностраничный сайт в редакционно-коллажном стиле isadeburgh.com.
Без сборки и зависимостей — открывается двойным кликом по `index.html`.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Вся разметка и весь текст |
| `style.css` | Стили, переменные цветов в `:root`, адаптив |
| `script.js` | Прелоадер, раскрытие, меню, форма, лента, курсор, анимации |
| `images/portrait-1160.jpg` | Ваше фото для десктопа (204 КБ) |
| `images/portrait-700.jpg` | То же фото для телефонов (90 КБ) |
| `IMG_9638.PNG` | Исходник фото, 1.9 МБ. На сайте не используется — можно удалить |
| `.claude/launch.json` | Конфиг локального сервера для превью |

## Структура

0. **Прелоадер** — счётчик 0 → 100 едет от левого края к правому, сверху полоса
   прогресса. Ход 0 → 94 сделан **чистым CSS** (`@keyframes dkBar/dkOut/dkBack/dkCount`
   в `style.css`), поэтому стартует на первом кадре, не дожидаясь `script.js`.
   Скрипт доводит 94 → 100, когда браузер сообщил о полной загрузке.
   Первый заход ~3,2 с, повторные в той же сессии ~0,9 с — флаг ставит
   встроенный скрипт в `<head>`, до первой отрисовки. Затем сайт
   раскрывается квадратом из центра
1. **Шапка** — ссылки, «Get in touch», соцсети. Монограмма `DK.` проявляется
   после прокрутки. На ширине ≤760px превращается в бургер и полноэкранное меню
2. **Имя** — во всю отведённую ширину, уменьшается при прокрутке (1 → 0.42)
3. **Hero** — дисциплины слева, фото справа со стикером; фото слегка следует за курсором
4. **Две бегущие строки** с инструментами
5. **Кейс `NORDWELL RETAIL`** — кредиты, текст, коллаж из «полароидов»
6. **Четыре проекта**, ряд круглых фото, два текстовых блока, широкий коллаж
7. **Таймлайн** 2026 → 2017 — горизонтальная лента: колесо мыши над ней листает
   вбок, снизу полоса прогресса и счётчик `01 / 07`. На телефоне — свайп
8. **Форма связи** — проверка полей на месте, отправка через почтовый клиент
9. **Футер** — крупный email и соцсети

## Что заменить на своё

1. **Кейсы** — Nordwell, Lumen, Verta, Ovi, Kastl вымышлены. Замените названия,
   цифры и описания на реальные.
2. **Ссылки на соцсети** — четыре `href="#"`, помечены `<!-- TODO -->`
   в шапке и футере.
3. **Домен в Open Graph** — в `<head>` стоит `https://example.com`. Подставьте
   реальный адрес, иначе превью в мессенджерах не подтянет картинку.
4. **Фото-заглушки** — всё, кроме портрета, со стока Pexels.
5. **Позиции в коллаже** — у карточек инлайн-стиль `--x` (лево, %), `--y` (верх, %),
   `--w` (ширина, %), `--r` (поворот). Правятся прямо в `index.html`.
6. **Цвета** — блок `:root` в `style.css` (`--green` — акцент).

## Форма

Бэкенда нет: поля проверяются на месте, затем открывается почтовый клиент
через `mailto:`. Чтобы письма приходили без почтовика, подключите Formspree /
Web3Forms — поставьте `action="https://formspree.io/f/ВАШ_ID" method="POST"`
и удалите последние строки обработчика `submit` в `script.js`.

## Доступность и устойчивость

- Без JavaScript сайт остаётся видимым (`<noscript>` в `<head>`)
- Все изображения с `alt` и заданными `width`/`height` — вёрстка не прыгает
- `prefers-reduced-motion` отключает анимации в CSS и в JS
- Видимая обводка при навигации с клавиатуры

## Публикация

- **Netlify Drop** — перетащить папку на app.netlify.com/drop
- **GitHub Pages** — залить в репозиторий, Settings → Pages → ветка `main`
- **Свой хостинг** — загрузить файлы в корень

## Локальный просмотр

Достаточно открыть `index.html`. Для http-сервера:

```bash
npx serve .
```
